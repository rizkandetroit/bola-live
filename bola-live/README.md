# Bola live

Dasbor pribadi: pertandingan 10 liga football-data.org (Premier League, Serie A, Bundesliga, La Liga, Ligue 1, Champions League, Eredivisie, Primeira Liga, Championship, Brasileirão) dan jadwal serta skor semua liga lain dari API-Football (tanpa prediksi), mulai 2 hari terakhir sampai 7 hari ke depan sejauh paket gratis mengizinkan, peluang menang beserta alasannya, skor paling mungkin, over/under 2,5 gol, kedua tim mencetak gol, dan halaman evaluasi akurasi. Diperbarui otomatis lewat GitHub Actions, tampil di GitHub Pages. Seluruhnya berjalan di paket gratis. Lihat `PANDUAN.md`.
